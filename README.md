# The Round Table: Benjamin Madan's portfolio

My personal portfolio, live at **[bmadann.github.io](https://bmadann.github.io)**.

The home page is a 3D castle hall in the spirit of the Knights of the Round Table. An ornate wooden table, with my name set into it in gold, stands before a roaring fireplace beneath a gilded lion's head, watched over by four suits of armour, with moonlight falling through a window and royal banners on the walls. Nine magical swords are planted in the table, each tied to an element (wind, fire, water, wood, earth, space, machinery, glass and time). You can walk the camera around the hall, zoom in on anything, and choose a sword to follow it to a different part of the site:

- **Resume** and **LinkedIn**
- **Projects:** one page for each of my GitHub projects, with an explanation of what it does and its source code
- **Class Work:** coursework from my classes, with each piece of code explained section by section

The site is plain HTML, CSS and JavaScript. The hall is rendered with [three.js](https://threejs.org), and every model, texture and effect in it is generated in code.
